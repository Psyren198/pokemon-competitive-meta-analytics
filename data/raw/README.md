# Raw Data

This directory contains documentation for the raw datasets used in the
Pokémon Competitive Meta Analytics project.

Raw source files may be excluded from Git when redistribution rights,
file size, or reproducibility requirements make direct storage
inappropriate.

Each dataset used in the project must be recorded in
`source_manifest.csv`, including its source, acquisition date, purpose,
format, and relevant usage or licensing notes.

Raw data should not be manually modified after acquisition.
Transformations and cleaned datasets belong in `data/processed/`.
